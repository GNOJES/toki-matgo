첫 판은 선고르기를 한다 [A]. 세부 방식은 미명시라 서로 한 장 추첨, 낮은 월 우선, 동률 재추첨으로 구현한다. 추첨패는 돌려놓고 다시 섞어 분배한다. 다음 판은 승자가 선. 나가리는 기존 선 유지.

## 상태와 턴 [A, B]

PLAY → (선택 필요시 SELECT_FLOOR) → 덱 뒤집기 → (선택 필요시 SELECT_FLOOR) → 획득 → 피 이동 → 점수 → GO_STOP 또는 다음 턴. 엔진은 순수 reducer이며 UI는 events를 순차 재생한다. 결정 대기 중 다른 행동은 거절한다.

- 같은 월 0장: 바닥에 둔다.
- 1장: 둘을 먹을 예정으로 보류한다(덱 뒤집기로 뻑 가능).
- 2장: 사용자가 한 장 선택한다. 덱도 같은 월이면 따닥으로 4장 모두 획득.
- 3장: 네 장 모두 획득. 뻑 소유자에 따라 피 이동.
- 보너스는 월 매칭 대상이 아니다. 뻑 더미에 붙은 보너스는 해당 뻑 획득자에게 간다.

폭탄 패스를 포함해 각자 10개의 정규 턴을 가진다. 보너스 내기는 정규 턴을 소모하지 않는다. 덱은 프로젝트 쌍피 구성과 정상 진행상 20개 정규 뒤집기를 제공한다. 마지막 정규 턴은 손패 수 대신 turnsRemaining으로 판정(폭탄 고려).

## 족보 [D, E]

- 광: 3장 3점, 비광 포함 3장 2점, 4장 4점, 5장 15점.
- 열끗: 5장 1점, 이후 +1점/장. 고도리(2·4·8월 열끗) +5점.
- 띠: 5장 1점, 이후 +1점/장. 홍단(1·2·3), 청단(6·9·10), 초단(4·5·7) 각각 +3점. 비띠는 초단 제외.
- 피: 합산 10피 1점, 이후 +1점/피. 쌍피/보너스는 2피.
- 국진: 기본 열끗. 획득자가 SET_KUKJIN으로 쌍피 전환 가능. 전환 후 열끗으로 돌아가지 않는다(공식 질문에 대한 명시적 구현 해석). 중복 계산 불가. 자신의 PLAY 상태에서만 변경 가능; 변경으로 7점/추가점이 나면 고/스톱 판정.

## 고/스톱과 최종 정산 [B, C]

기본점수 7점부터 고/스톱 선택. 고 후에는 선언 시 기본점수보다 높아져야 재선택한다. 마지막 자신의 정규 턴에는 고 없이 자동 스톱. 두 사람 모두 턴 종료 때까지 추가점 없이 끝나면 나가리.

기본점수 = 광 + 열끗 + 고도리 + 띠 + 홍단 + 청단 + 초단 + 피.

최종 = (기본 + min(고횟수, 2)) × 2^max(고횟수−2, 0) × 흔들기/폭탄 × 피박 × 광박 × 멍따 × 고박 × 전판나가리.

1고 +1, 2고 +2, 3고 ×2, 4고 ×4, 5고 ×8(가산 2는 유지).
흔들기 또는 폭탄 각각 ×2. 피박: 승자 피 점수 ≥1, 패자 7피 이하(0 포함) ×2. 광박: 승자 광 점수 >0, 패자 광 0 ×2. 멍따/멍박: 승자 열끗 7장 이상 ×2. 고박: 상대가 마지막으로 고한 상태에서 내가 스톱하면 ×2(공식 C 독박 문구의 2인 해석). 고 선언권은 마지막 선언자 하나만 유지한다. 나가리 다음 판 ×2, 연속 나가리는 누적하지 않음(공식 C는 바로 다음 판의 2배만 명시).

결과는 각 점수와 배수를 구조적으로 반환한다. 금전 대신 첫뻑/첫따닥 등 즉시 정산은 sidePoints에 기록하고 세션 점수에 더한다. 나가리에서도 sidePoints는 보존.

## 특수 상황 [B, C]

| 상황    | 판정                                      | 처리                                                        |
| ------- | ----------------------------------------- | ----------------------------------------------------------- |
| 뻑      | 바닥 1장에 낸 패와 뒤집은 패가 같은 월    | 3장 바닥 잔류, 뒤집기 보너스도 해당 월에 부착               |
| 자뻑    | 자신이 만든 뻑 획득                       | 상대 2피 탈취                                               |
| 상대 뻑 | 상대가 만든 뻑 획득                       | 상대 1피 탈취                                               |
| 첫뻑    | 자신의 첫 정규 턴 뻑                      | 즉시 7점                                                    |
| 2·3연뻑 | 첫 턴부터 자신의 연속 2·3번째 뻑          | 즉시 14·21점                                                |
| 3뻑     | 누적 3회(불연속 포함)                     | 7점 승리, 이미 얻은 즉시점수 별도                           |
| 따닥    | 바닥 2장과 낸 패/뒤집은 패 같은 월        | 4장 획득, 1피 탈취; 첫 턴 7점 즉시                          |
| 쪽      | 바닥 매치 없음, 낸 패와 뒤집은 패 같은 월 | 2장 획득, 1피 탈취                                          |
| 판쓸이  | 턴 획득 후 바닥 비움                      | 1피 탈취                                                    |
| 흔들기  | 손 같은 월 3장, 바닥 해당 월 없음         | 선택 선언 후 공개, 승리 배수 ×2; 월당 1회                   |
| 폭탄    | 손 같은 월 3장, 바닥 나머지 1장           | 4장 획득, 1피 탈취, 승리 배수 ×2, 이후 덱만 뒤집기 2회 권리 |
| 총통    | 초기 손 같은 월 4장                       | 즉시 10점 승리, 들고치기 없음; 양쪽 총통이면 나가리(해석)   |
| 허당    | 연속 자신의 5턴 획득 없음                 | 7점 즉시 승리 [C]                                           |

마지막 정규 턴은 뻑·쪽 제외 [B]. 판쓸이·따닥 피 탈취도 마지막 정규 턴에는 제외(명시적 마지막 패 해석). 마지막 뻑 형태는 첫 2장 획득하고 뒤집은 패는 바닥에 남긴다. 폭탄 패스 턴도 정규 턴이다.

피 탈취는 피 단위로 계산, 홑피 우선. 홑피가 없으면 쌍피 1장이 이동하므로 1피 요청에 2피가 갈 수 있음(해석). 국진은 쌍피 전환 후에만 탈취 가능. 상대에게 피가 없으면 효과 없음. 한 턴 여러 특수 효과는 합산. 보너스 자체는 피 탈취를 발생시키지 않는다.

## 보너스 [D; 프로젝트 변경]

초기 바닥: 선 획득 후 보충. 손에서 냄: 획득 → 덱 한 장을 손으로 보충 → 같은 플레이어 계속(고/스톱은 정규 턴 종료까지 보류). 뒤집기: 추가 뒤집기 반복. 뻑이면 뒤집은 보너스는 바닥 뻑 더미에 잔류. 쌍피 2장 모두 한 사람에게 가면 4피. 쓰리피·보너스 탈취 없음.

## 종료와 검증

스톱, 마지막 턴의 유효 점수, 총통, 3뻑, 허당으로 승패 확정. 정규 턴 모두 소진되고 승패 미확정이면 나가리. 재접속/통신 지연으로 패배시키지 않음. 턴 제한시간 없음.

모든 action은 턴/소유권/phase/선택을 검증하고 immutable nextState + 공개 events 반환. 카드 위치(손/바닥/덱/획득/턴 보류) 총 50장, 중복/유실 없음. production에서도 검증. stateVersion은 성공 행동마다 +1. 거절 시 기존 state 보존. 공개 손 흔들기는 선택한 3장만 공개, 상대 손 전체/미래 덱은 전송 금지.

미션, 족보 미션, 월 미션, 이벤트 배수, 2장 폭탄, 베팅, 게임머니 없음.
