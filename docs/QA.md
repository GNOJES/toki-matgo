## 수동 브라우저 확인

화투 교체 후 Marcus Richert 원본 48장의 광/열끗/띠/피와 한국식 11월 오동·12월 비 대응을 contact sheet로 확인했다. Chromium/WebKit 4개 크기의 E2E 10개와 빌드·타입 검사 모두 통과했다. production PWA는 WebP 48장 캐시를 확인하고 오프라인 재로딩 후 손패 10장의 실제 이미지 로딩과 패 내기를 검증했다. 모바일 화면 검증은 총통으로 즉시 끝나는 무작위 분배를 피하도록 테스트 context에 고정 RNG를 사용한다.

## 알려진 운영 한계

Firebase Emulator Suite 검증이며 운영 DB/실제 스마트폰 검증은 수행하지 않았다. 방장 브라우저가 끊기면 판정이 멈춘다. 익명 UID 분실 복구·방장 교체·치팅 방지는 없다. 방은 24시간 유효하고 명시적 나가기는 삭제하며 만료/종료 방은 다음 방 생성 시 정리하고, 만료 숫자 코드는 재사용한다. 아무도 접속하지 않을 때 실행되는 주기적 정리는 없다. Firebase 무료 사용량 한도가 있다. Legacy MemoryRoomStore의 재시작/replica 한계는 현재 운영 경로와 무관하다.

최신 추가 검증: 숫자 4자리(앞자리 0 포함) 생성, 활성 코드 충돌 회피, 만료 코드 재사용, 제3자의 활성 방 삭제 차단, 역할별 빈 이름 기본값. 360×740 / 390×844 / 412×915에서 12개월 바닥패와 중앙 덱의 좌표·크기·비중첩을 확인했다. 시작 보너스 2장 연속 획득·보충은 양쪽 선 모두 검증했고, 뻑 보너스가 해당 월 더미에 표시됨을 확인했다. 연결 대기 중 행동 금지와 종료 안내 확인 후 삭제된 방을 재생성하지 않는 경로도 검증했다.

## 보너스·폭탄·피 강탈 연출 검증

Chromium / WebKit에서 보너스 손패 사용 시 중앙 덱 중심까지 이동해 잠시 표시된 뒤 아래쪽 피 획득 영역으로 들어오는 좌표를 확인했다. 바닥에 독립적인 보너스 더미는 생성하지 않는다. 폭탄 사용 뒤 손패에 뒤집기 카드 2장이 생기고 한 장을 사용하면 1장만 남는지, 별도 덱 뒤집기 버튼이 없는지 확인했다. 피 강탈은 상대 피 카드 중심에서 출발하며 이동 중 원본은 숨겨 두 장처럼 보이지 않게 한다. 12개월 전체 배치에서도 중앙 덱과 바닥패 크기 일치·비중첩, 기존 패 자리 고정 검증이 통과했다.

## 최근 기록 검증

Chromium / WebKit에서 실제 혼자 치기 3판 완료 → 홈·새로고침 → 최근 기록 3개 확인 → 새로운 혼자 치기 완료 → 누적 4판 확인 → 초기화 취소 → 확인 후 초기화 → 새로고침 후 0판 유지 경로를 검증한다. 360×740 / 390×844 / 412×915에서 세 번째 홈 메뉴가 화면 내에 표시되는지, Back이 초기화 확인창과 기록창을 순서대로 닫는지, 초기화가 친구 기록을 유지하는지 확인한다. 멀티 2 context 완료 결과는 각자 자신의 관점으로 1회 기록되며 혼자 치기 누적 통계에 합산하지 않는지 검증한다. 단위 테스트는 130판의 목록 제한과 전체 누적 보존, 중복 결과, 무승부·즉시 점수·초기화 범위와 손상 저장소 복구를 확인한다.

## 국화 선택·바닥 배치·이벤트 시인성 검증

국화 자동 선택 시 전환 8점/유지 6점 비교, 수동 창 Back 닫기, 필수 창 Back 유지, 전환 후 피 그룹 이동과 고/스톱 진입을 Chromium / WebKit에서 확인했다. 단위 테스트는 선택으로 정규 턴이 두 번 소비되지 않는지, 유지 시 다음 턴 진행, 마지막 턴 스톱, AI 선택을 확인한다. Firebase 실제 SDK와 기존 Rules를 사용한 에뮬레이터 검증은 방장의 전환과 참가자의 유지, 동일한 공개 상태를 확인한다.

360×740 / 390×844 / 412×915에서 손패·바닥패·덱 폭 일치, 12개월 카드와 덱 비중첩을 검증했다. 전체 40개 중 좌표 검사 1개에서 새 분배 렌더링 중 측정 문제가 발견되어, 카드 높이 고정과 새 fixture 카드 ID·이미지 로딩 완료 대기를 반영한 뒤 해당 검사를 양 브라우저에서 각각 3회 반복 통과했다. 다른 39개도 통과했다. 폭탄의 밝은 굵은 글자와 26px 이상 크기, 피 이동 중 지속 표시를 확인했다. production 빌드와 PWA 2개도 통과했다. 실제 기기 Back 검증과 운영 DB 두 폰 검증은 기존 수동 확인 항목으로 남는다.
